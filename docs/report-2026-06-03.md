## Platform Details

### ChatGPT Enterprise (OpenAI) — Codex enterprise expansion (June 2, 2026)

- **Codex "Sites" (preview, Business/Enterprise) — agent-built, OpenAI-hosted web apps & dashboards**: The Codex app's new Sites plugin turns a prompt or compatible project into a deployed site hosted by OpenAI — websites, dashboards, internal tools, web apps, planners, review workspaces, project boards, galleries, and games. Sites hosts projects that build Cloudflare Worker–compatible output as ES modules. Workflow: validate the build → save a deployable version for review → deploy the approved version. Each project has its own hosted environment variables and secrets (managed in the Sites panel), a deployment status, a workspace-shareable URL, and access controls the agent can change ("change who can access a deployed site"). Rolling out to Business and Enterprise plans first, with enterprise admin enablement via role-based access control. Source: https://developers.openai.com/codex/sites
- **Codex on ChatGPT for iOS 1.2026.146 — SSH to Windows + biometric lock**: Adds SSH connection support so the mobile Codex app can connect to Windows machines, an optional Face ID/passcode lock for Codex, and a settings screen for follow-up behavior and code diff preferences. Source: https://developers.openai.com/codex/changelog

## New Coverage Required

- **[AISPM] [HIGH] OpenAI Codex "Sites" — agent-deployed, OpenAI-hosted applications**: As of June 2, 2026 (preview, Business/Enterprise), the Codex app's Sites plugin lets a Codex agent create, save, deploy, and inspect full websites, dashboards, internal tools, web apps, and games **hosted by OpenAI** (Cloudflare Worker–compatible ES-module output). Each Site is a new inventory entity carrying its own hosted environment variables and secrets, a deployment lifecycle (saved → approved → deployed), a workspace-shareable URL, and access controls the agent itself can modify. AISPM must discover and map these new entities — Codex Sites projects, their stored secrets/env vars, deployment status, and sharing/access scope — and flag toxic combinations such as an agent that both holds secrets and can deploy a publicly reachable app *and* widen its audience (an agent-controlled exposure/exfiltration path). This is an entirely new service surface, not an extension of an existing one. Source: https://developers.openai.com/codex/sites
- **[AIRT] [HIGH] Codex Sites as a new agent-controlled deployment/exposure attack surface**: Because a Codex agent can deploy live, OpenAI-hosted endpoints and change who can access them, a prompt-injected or misdirected Codex session becomes a vector to stand up or repoint a public web app, embed/exfiltrate secrets via a Site's stored environment variables, or broaden a Site's audience without human review. AIRT should add Codex Sites deploy/share/secret-management actions to its red/purple-team surface for OpenAI agents — testing prompt-injection paths that result in unauthorized deployment, audience widening, or secret exposure. Source: https://developers.openai.com/codex/sites
- **[ENDPOINT] [MEDIUM] Codex (ChatGPT iOS 1.2026.146) adds SSH connections to Windows machines**: The June 2, 2026 ChatGPT iOS release adds SSH connection support so the mobile Codex app can connect to Windows machines (alongside an optional Face ID/passcode lock for Codex). This extends Codex's remote-execution reach — previously remote control / Computer Use on Windows — to direct SSH sessions into Windows hosts from a mobile device. ENDPOINT should treat a mobile Codex install with SSH access to Windows endpoints as a new remote-execution/credential surface on monitored machines. Source: https://developers.openai.com/codex/changelog
