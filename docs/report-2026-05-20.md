## Platform Details

### Anthropic (Claude Enterprise)
- **Anthropic acquires Stainless (May 18, 2026)**: $300M+ acquisition of the SDK-generation startup whose tooling powers every official Anthropic SDK and is also used by OpenAI, Google, Cloudflare. Hosted Stainless products (including the SDK generator) will be wound down. Strategic intent is to control SDK and MCP-server tooling for the AI agent ecosystem. Source: https://www.anthropic.com/news/anthropic-acquires-stainless
- **KPMG Strategic Alliance + KPMG Digital Gateway Powered by Claude (May 19, 2026)**: Global alliance deploying Claude to 276,000+ KPMG employees worldwide. Claude is embedded inside KPMG Digital Gateway — KPMG's client-delivery platform — starting with new tools for tax and legal clients. KPMG is also named Anthropic's preferred PE partner; joint Claude-powered products for PE portfolio companies are planned. Source: https://www.anthropic.com/news/anthropic-kpmg

### OpenAI Codex
- **Codex CLI 0.132.0 (May 20, 2026)**: Python SDK authentication expansion — API key login, ChatGPT browser flow, device-code flows. Text-based workflows now accept plain string inputs; resumed automations retain session context with structured output. Source: https://github.com/openai/codex/releases/tag/rust-v0.132.0
- **Codex CLI 0.131.0 (May 18, 2026)**: Unified `@` mentions across files, directories, plugins, and skills. Plugin marketplace CLI commands with version-aware sharing, share checkout, clearer shared-workspace buckets, and default-enabled plugin hooks. Remote environments now support a daemon-managed `codex remote-control`, with runtime enable/disable APIs, status reads, and registry-backed configuration. Source: https://github.com/openai/codex/releases/tag/rust-v0.131.0

### Cursor
- **Cursor in Jira (May 19, 2026)**: New integration. Jira work items can be assigned directly to cloud agents, or users can `@Cursor` mention in Jira comments. The system pulls ticket context to scope the task and opens a pull request when complete. Source: https://cursor.com/docs/integrations/jira
- **Composer 2.5 (May 18, 2026)**: New Cursor in-house coding model built on the Kimi K2.5 base from Moonshot AI, with 85% of compute spent on Cursor's RL/post-training. Matches Claude Opus 4.7 on key coding benchmarks at ~1/10 the cost; trained on 25× more synthetic coding tasks than Composer 2. Pricing: Standard $0.50/$2.50 per M input/output tokens; Fast (default) $3.00/$15.00. Source: https://cursor.com/blog/composer-2-5

### ServiceNow
- **AI Control Tower expansion (Australia release, GA expected Aug 2026; Innovation Lab in May 2026)**: AI Control Tower now operates across five areas — discovery, observation, governance, security, and measurement — and adds 30 new enterprise connectors that reach beyond ServiceNow into AWS, Google Cloud, Azure, SAP, Oracle, and Workday. Adds enforcement / agent kill-switch capabilities. Source: https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-expands-AI-Control-Tower-to-discover-observe-govern-secure-and-measure-AI-deployed-across-any-system-in-the-enterprise/default.aspx
- **Project Arc — autonomous desktop agent (Australia release, May 2026)**: New ServiceNow autonomous desktop agent that resides on employee desktops and completes work autonomously. Secured by Nvidia OpenShell runtime; governed by ServiceNow AI Control Tower. Source: https://www.servicenow.com/products/ai-control-tower.html

### Azure AI Foundry / Azure OpenAI
- **GPT Realtime 2.0 (preview, May 2026)**: New speech-to-speech model with built-in reasoning. Adjustable `reasoning.effort` (minimal/low/medium/high), response phases distinguishing preambles ("commentary") from final answers ("final_answer"), and an extended 256K-token context window. Same connection/usage patterns as earlier realtime models. Source: https://learn.microsoft.com/en-us/azure/foundry/openai/concepts/realtime-2
