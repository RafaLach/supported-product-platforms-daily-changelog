The week's headline finding is **Microsoft Agent 365 went GA on May 1, 2026** — a new Microsoft control plane for observing, governing, and securing AI agents across the enterprise — surfaced in this scan because it now appears as a top-line product in the M365 Copilot extensibility navigation. ## Platform Details

### Microsoft Agent 365 (new product surface)
- **Microsoft Agent 365 — GA May 1, 2026**: New per-user-licensed Microsoft product ($15/user/mo, Commercial segment) for observing, governing, and securing AI agents. Three pillars — **Observe** (Agent registry, Registry sync, Agent Map showing all agents in a single centralized registry in the M365 admin center), **Govern** (lifecycle management, access control, compliance through M365 admin center + Microsoft Entra + Microsoft Purview), **Secure** (Entra Conditional Access for agents, Purview DLP/info-protection, Defender real-time runtime protection). At launch, a set of **pre-integrated ecosystem partner agents** are deployable directly from the M365 admin center. Source: https://www.microsoft.com/en-us/security/blog/2026/05/01/microsoft-agent-365-now-generally-available-expands-capabilities-and-integrations/
- **Agent registry in the Microsoft 365 admin center**: New centralized agent inventory surface in the M365 admin center, with **Registry sync** to pull external agent inventory and **Agent Map** for visualization. Source: https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-registry
- **Microsoft Defender — real-time agent protection during runtime**: New Defender feature blocks unsafe behaviors and malicious activity for agents at runtime. Source: https://learn.microsoft.com/en-us/defender-cloud-apps/real-time-agent-protection-during-runtime
- **Microsoft Purview — AI agent governance for Agent 365**: New Purview surface for managing data security and compliance for Agent-365-registered agents. Source: https://learn.microsoft.com/en-us/purview/ai-agent-365

### Amazon Bedrock AgentCore
- **AgentCore Payments (preview)**: New managed service enabling microtransaction payments for AI agents using the **x402 protocol**. Wallet integration with **Coinbase CDP** and **Stripe (Privy)**. Built-in budget controls per `PaymentSession` (configurable `maxSpendAmount`, currency, expiry). Pre-integrated **Coinbase x402 Bazaar MCP server** exposing 10,000+ pay-per-use x402 endpoints via AgentCore Gateway. New API surface: `CreatePaymentInstrument`, `CreatePaymentSession`, `ProcessPayment`, `GetPaymentInstrumentBalance`, `GetResourcePaymentToken`, plus a new `PaymentCredentialProvider` resource stored in AgentCore Identity. Available in us-east-1, us-west-2, eu-central-1, ap-southeast-2. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments.html
- **AgentCore Harness (preview)**: New managed agent harness/loop powered by **Strands Agents** (AWS's open-source agent framework). Each session runs in **isolated microVM** with its own filesystem and shell. Persistent short-term and long-term memory across sessions; **mid-session model switching** (Bedrock, OpenAI, Google Gemini). BYO custom container environment. Harness config exports to Strands Agents code. Available in us-west-2, us-east-1, ap-southeast-2, eu-central-1. New API: `InvokeHarness`. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/harness.html
- **AgentCore Registry**: New centralized catalog for agents, MCP servers, tools, skills, and custom resources across an organization. Provides governed publish/review/approve workflow with hybrid semantic + keyword search. New API: `SearchRegistryRecords`. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/registry.html
- **AgentCore Policy**: Cedar-based deterministic policy controls (in addition to natural-language rules) that intercept every tool call in AgentCore Gateway before execution. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/policy.html
- **AgentCore Evaluations — A/B testing APIs**: New `CreateABTest`/`GetABTest`/`UpdateABTest`/`DeleteABTest`/`ListABTests` APIs alongside `StartBatchEvaluation`/`GetBatchEvaluation` for purpose-built evaluations across sessions/traces/spans. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/evaluations.html

### Azure AI Foundry / Azure OpenAI
- **GPT Realtime Translate (preview, May 2026)**: New realtime model for continuous stream-based audio translation for live multilingual events, customer support, and voice assistants. Same `/realtime` endpoint surface. Source: https://learn.microsoft.com/en-us/azure/foundry-classic/openai/concepts/gpt-realtime-translate
- **GPT Realtime Whisper (preview, May 2026)**: New low-latency streaming transcription model for live captions, monitoring, and archival workflows. Same `/realtime` endpoint surface. Source: https://learn.microsoft.com/en-us/azure/foundry-classic/openai/concepts/gpt-realtime-whisper

### Cursor
- **Cursor Automations 2.0 (May 20, 2026)**: Major expansion. Automations now live in the **Agents Window** workspace (previously cursor.com/automations only). New **multi-repository support** — a single automation can attach multiple repos, allowing the cloud agent context to span codebases; Dockerfile-based environment configuration with build-secrets support for private package registries. New **no-repository automations** — automations can run without any repo attached, for operational/non-code tasks. Five new marketplace templates: **Slack digest agent**, **product analytics agent**, **product FAQ agent**, **product finance agent**, **customer health monitoring agent**. Source: https://forum.cursor.com/t/improvements-to-cursor-automations/161149

### Perplexity
- **finance_search tool in Agent API (May 2026)**: New tool added to the Perplexity `/v1/agent` endpoint for structured financial and market data — quotes, financials, earnings, analyst estimates, segment KPIs, ETF constituents, insider activity, market movers, ETF constituents, index details. Joins the existing tool set: `web_search`, `people_search`, `fetch_url`, function tools. Billed at $5 per 1,000 invocations (model tokens billed separately). Source: https://docs.perplexity.ai/docs/agent-api/finance-search

### Salesforce AgentForce
- **"Topics" renamed to "Subagents" (April 2026)**: AgentForce agent **topics** have been renamed to **subagents** organization-wide in the developer documentation to better reflect their role as specialized agents with specific expertise. No functional change, but documentation transitions both terms during migration. Source: https://developer.salesforce.com/blogs/2026/05/new-agentforce-metadata-and-development-lifecycle

## New Coverage Required

- **[AISPM] [HIGH] Microsoft Agent 365 — observe/govern/secure control plane GA**: New Microsoft product (GA May 1, 2026, $15/user/mo) that is a direct competitor surface to Zenity AISPM. Introduces a centralized **Agent registry** in the M365 admin center, **Registry sync** (pulls external agent inventories), and an **Agent Map** for visualization — plus tight integrations with Entra (agent identity, Conditional Access for agents), Purview (DLP, AI agent risk), and Defender (real-time runtime protection). Pre-integrated ecosystem partner agents deploy directly from the admin center. AISPM must track tenants enabling Agent 365 as a distinct governance class, reconcile Agent 365 inventory against Zenity's, and recognize Agent-365-registered agents as an inventory-source-of-truth signal. AIDR should detect when Defender's real-time-agent-protection blocks an action and treat it as a coverage handoff. Source: https://learn.microsoft.com/en-us/microsoft-agent-365/overview
- **[AISPM] [HIGH] AgentCore Payments — agent-driven microtransactions over x402 protocol**: Brand-new AgentCore service (preview) that lets agents autonomously spend money. Introduces multiple new inventory entities: `PaymentInstrument`, `PaymentSession` (with `maxSpendAmount`, currency, expiry), and `PaymentCredentialProvider` (wallet creds for Coinbase CDP and Stripe-Privy stored in AgentCore Identity). Wires in 10,000+ third-party paid endpoints via the pre-integrated **Coinbase x402 Bazaar MCP server** through AgentCore Gateway. AISPM must inventory each agent's payment instruments, sessions, and budget caps; new toxic-combination class: overprivileged agent + active PaymentSession + unrestricted Gateway target. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments.html
- **[AIDR] [HIGH] AgentCore Payments — payment data flow + spending observability**: Each payment flow emits CloudWatch vended logs + X-Ray vended spans for every data-plane API call. AIDR gains an entirely new activity-type stream — payment requests, x402 challenge responses, wallet-signing events, budget-deduction events, failed-signing exceptions — and a new detection surface for runaway agent spending. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments-how-it-works.html
- **[AIRT] [HIGH] AgentCore Payments — x402 + crypto-wallet attack surface**: Three distinct new attack surfaces: (a) `PaymentSession` budget bypass via session reuse or expiry races, (b) wallet credential exfil from `PaymentCredentialProvider` (Coinbase API keys, Stripe-Privy secrets) stored in AgentCore Identity, (c) malicious x402-Bazaar MCP endpoints draining agent budgets through inflated micro-charges or fee inflation. AIRT should add automated tests for x402 payment-required flow tampering, budget-cap evasion, and prompt-injection-driven payment authorization. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments-concepts.html
- **[AISPM] [HIGH] AgentCore Harness — managed agent-loop runtime with microVM sessions**: New preview service replacing the bespoke agent harness with a managed loop powered by Strands Agents. Each session runs in an isolated microVM with filesystem and shell access, persistent short-term + long-term memory across sessions, and **mid-session model switching** (Bedrock, OpenAI, Gemini). New API `InvokeHarness` and a distinct session resource class. Harness config can be exported to Strands Agents code. AISPM must inventory Harness sessions per agent, capture the model-provider trail across mid-session swaps, and treat BYO container images as a custom-environment inventory class. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/harness.html
- **[AISPM] [HIGH] AgentCore Registry — central agent/tool/MCP-server catalog**: New AgentCore service that catalogs every agent, MCP server, tool, skill, and custom resource across an organization with governed publish/review/approve workflows and hybrid semantic+keyword search. Functions as a customer-side AISPM signal source — Zenity can reconcile its inventory against Registry entries, and Registry's approval state becomes a new policy attribute (approved vs unapproved tool, deployed where). New API `SearchRegistryRecords`. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/registry.html
- **[AISPM] [MEDIUM] AgentCore Policy — Cedar-based pre-execution policy enforcement**: AgentCore Policy now exposes Cedar (AWS's open-source policy language) in addition to natural-language rules, and intercepts every tool call in AgentCore Gateway before execution. New policy resource class with deterministic rule semantics that AISPM should treat as authoritative for tool-execution authorization decisions. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/policy.html
- **[AISPM] [MEDIUM] AgentCore Evaluations — A/B testing APIs**: New `CreateABTest`/`UpdateABTest`/`DeleteABTest`/`ListABTests` plus `StartBatchEvaluation`/`StopBatchEvaluation` APIs extend evaluation from sessions/traces/spans into A/B test resources. New `ABTest` inventory class with associated batch evaluation runs; AISPM should map ABTest → agent variants → traffic-split signals. Source: https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/evaluations.html
- **[AIDR] [HIGH] Azure OpenAI — GPT Realtime Translate (live multilingual audio streaming)**: New realtime model dedicated to continuous stream-based audio translation. Same `/realtime` endpoint as other realtime models, but introduces a translation-specific data flow — source-language audio in, target-language audio out — for live multilingual events, customer support, and voice assistants. New AIDR signal class: cross-language audio-to-audio session, where source and target language attributes need separate tracking. Source: https://learn.microsoft.com/en-us/azure/foundry-classic/openai/concepts/gpt-realtime-translate
- **[AIDR] [HIGH] Azure OpenAI — GPT Realtime Whisper (low-latency streaming transcription)**: New realtime ASR model for live captions, monitoring, and archival workflows on the `/realtime` endpoint. Distinct from prior `gpt-4o-transcribe-*` chains in that transcription is now a first-class realtime modality. AIDR gains a streaming-transcript activity type for archival and monitoring traffic categories. Source: https://learn.microsoft.com/en-us/azure/foundry-classic/openai/concepts/gpt-realtime-whisper
- **[ENDPOINT] [HIGH] Cursor — Automations 2.0 (multi-repo, no-repo, marketplace templates)**: Cursor Automations expand beyond the standalone web UI into the Agents Window. Three new endpoint sub-classes: (a) **multi-repo automations** — one automation spans multiple attached repos, breaking the 1:1 repo↔agent assumption; (b) **no-repository automations** — operational tasks (e.g. Slack digest, customer-health monitoring) without any code surface, which extends Cursor as a general-purpose autonomous agent platform rather than just a coding agent; (c) **marketplace templates** as a discoverable distribution channel for shared automation patterns (Slack digest, product analytics, FAQ, finance, customer-health agents). ENDPOINT must update the Cursor inventory model to treat automations as a distinct endpoint class with N-repo or zero-repo binding; AISPM should map automation → triggered cloud-agent runs → connected data sources. Source: https://forum.cursor.com/t/improvements-to-cursor-automations/161149
- **[AISPM] [MEDIUM] Perplexity — finance_search tool in Agent API**: New `finance_search` tool added to the Perplexity Agent API (`POST /v1/agent`) for structured financial/market data — quotes, financials, earnings, analyst estimates, segment KPIs, ETF constituents, insider activity, market movers.
