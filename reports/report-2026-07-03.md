## Platform Details

### Microsoft Copilot Studio
- **New agent experience (production-ready preview, June 2026)** — an enhanced orchestration runtime for improved response quality and reasoning, available alongside the classic experience. New agent build model/runtime. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/overview
- **Microsoft IQ (June 2026)** — connects an agent to organizational data: emails, calendar events, files, Teams messages, and people information. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/use-microsoft-iq
- **Skills (June 2026)** — modular, self-contained sets of instructions; created once, added to multiple agents, and exportable as a Markdown file or package to share. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/skills-overview
- **Memory (June 2026)** — persistent per-user context that captures user preferences/patterns, stores them per user, and applies them over time. Source: https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/memory-overview

### Claude Enterprise (Anthropic)
- **Claude Tag (June 23, 2026)** — a new way for teams to work with Claude, starting in Slack where Claude joins as a team member. Teams grant @Claude channel access and connect it to chosen tools, data, and codebases; admins scope access per channel and can create separate Claude identities per use. Beta for Enterprise & Team. Source: https://www.anthropic.com/news/introducing-claude-tag
- **Claude Sonnet 5 (June 30, 2026)** — new agentic model (`claude-sonnet-5`) that plans, uses browsers/terminals, and runs autonomously near Opus 4.8 capability; available via Claude API, AWS, and Microsoft Foundry; default for Free/Pro. New tokenizer. Source: https://www.anthropic.com/news/claude-sonnet-5
- **Claude Science AI Workbench (June 30, 2026)** — a research environment that builds environments and manages compute on the user's laptop, cluster, or on-demand GPUs (asks before reaching new resources; reviewable/revocable), integrates researcher tools/packages, and renders scientific artifacts. Source: https://www.anthropic.com/news/claude-science-ai-workbench

### ChatGPT Enterprise (OpenAI)
- **Codex app 26.616 — Record & Replay + Thread handoff (June 18, 2026)** — Record & Replay (macOS) turns user-demonstrated workflows into reusable agent skills; Thread handoff moves conversations (with browser tab routing/annotations) between local and remote hosts. Source: https://developers.openai.com/codex/record-and-replay
- **Codex CLI 0.141/0.142 (June 2026)** — per-thread stdio MCP servers (per-conversation MCP tool surface), Noise-relay E2E-encrypted remote execution, configurable multi-agent delegation modes (disabled / explicit-request-only / proactive), and indexed web-search mode. Source: https://developers.openai.com/codex/changelog
- **OpenAI Node SDK v6.45.0 (June 24, 2026)** — Realtime API "sideband call_id connections," Responses input-items + stream-accumulator helpers, and a tool-runner `afterCompletion` hook. Source: https://github.com/openai/openai-node/releases/tag/v6.45.0

### Cursor
- **iOS mobile app + Remote Control (June 29, 2026)** — native iPhone app (public beta) to launch/manage cloud and local agents with voice input, and to remotely direct a desktop agent (agent loop moves to cloud while tools keep running on the user's machine). Source: https://cursor.com/docs/cloud-agent/mobile
- **Team/organization MCP marketplace distribution (June 30, 2026)** — admins configure Team MCP servers once and distribute them across cloud agents, IDE, and CLI via marketplace configs, gated by organization group access controls. Source: https://cursor.com/docs/mcp
- **Automations: computer-use + new GitHub/Slack triggers (June 18, 2026)** — Automations can perform computer-use and be triggered by five new GitHub events plus a Slack emoji-reaction trigger; authorable in-session via `/automate`. Source: https://cursor.com/changelog
- **Cloud subagents via `/in-cloud` (June 17, 2026)** — spawns isolated cloud subagents for parallel work with automated environment setup and reusable snapshots. Source: https://cursor.com/changelog
