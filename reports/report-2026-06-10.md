## Platform Details

### Claude Enterprise (Anthropic)

- **Claude Fable 5 and Claude Mythos 5** (June 9, 2026): Anthropic's first publicly available **Mythos-class** models. **Fable 5** is the safeguarded public release (state-of-the-art across software engineering, knowledge work, vision, and scientific research; conservatively tuned safeguards route ~<5% of high-risk sessions to Claude Opus 4.8). **Mythos 5** is the same underlying model with safeguards lifted in some areas, deployed to a small set of cyberdefenders/infrastructure providers via **Project Glasswing** (US government collaboration), described as having "the strongest cybersecurity capabilities of any model in the world." Priced at $10/M input, $50/M output; also available on **AWS Bedrock**. Source: https://www.anthropic.com/news/claude-fable-5-mythos-5

### ChatGPT Enterprise (OpenAI)

- **Codex worktree creation + automatic environment setup scripts** (June 9, 2026, ChatGPT for iOS 1.2026.153): Codex worktree creation can now optionally run a **local environment's setup scripts automatically** at the start of a new thread — "run any command required to configure your environment" (install dependencies, run a build). The new-thread flow lets the agent select a worktree, choose the local environment whose setup scripts run, and pick the Git branch to base the worktree on. Branch selection, the `/goal` objective-management command, and a usage-statistics profile screen also landed on the **iOS** client. Source: https://developers.openai.com/codex/app/worktrees

## New Coverage Required

- **[AIRT] [HIGH] Anthropic Claude Fable 5 / Mythos 5 (new Mythos-class model line)**: Anthropic released its first public Mythos-class models on June 9 — Fable 5 (safeguarded, public) and Mythos 5 (safeguards lifted, deployed via Project Glasswing), the latter described as having the strongest cybersecurity capabilities of any model in the world. These are entirely new model identities (not an Opus/Sonnet/Haiku version bump), introducing a new model attack surface for automated red/purple teaming: new capability ceilings to probe, a novel guardrail-fallback behavior (Fable 5 silently routing high-risk prompts to Opus 4.8) that AIRT can test for bypass/inconsistency, and frontier cyber capabilities that change the risk profile of any agent wired to these models. AISPM must also add `fable-5` / `mythos-5` as discoverable model entities — including on AWS Bedrock, where Fable 5 is now selectable. Source: https://www.anthropic.com/news/claude-fable-5-mythos-5
