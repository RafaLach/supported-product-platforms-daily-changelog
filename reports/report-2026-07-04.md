## Platform Details

### Azure AI Foundry
- **Foundry MCP Server** — a Model Context Protocol server for Foundry (no infra to deploy) that enforces Entra ID auth/authorization via On-Behalf-Of flow and exposes a growing set of read/write tools over Foundry models, deployments, evaluations, and agents to MCP clients and coding agents. Source: https://learn.microsoft.com/en-us/azure/foundry/mcp/get-started
- **Foundry Skill in coding agents** — a reusable skill that plugs into coding agents to standardize Foundry workflows (deployment, evaluation, prompt optimization, dataset curation from traces, troubleshooting); bundled with the Azure Skills Plugin alongside the Foundry MCP Server. Source: https://learn.microsoft.com/en-us/azure/foundry/how-to/develop/use-microsoft-foundry-skill
- **Hosted agents (Foundry Agent Service) + prompt-agent quickstart** — containerized, own-code agents deployed to Microsoft-managed infra; each deployment is assigned a dedicated Microsoft Entra ID (agent identity) and dedicated endpoint, and published agents can be shared through M365 Copilot / Teams and the Entra Agent Registry. New agent deployment/sharing surface distinct from prompt-based agents. Source: https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/hosted-agents
- **Foundry Control Plane** — a unified control plane to track/manage agents from supported platforms across projects in one view, with cross-project visibility, unified compliance enforcement, integrated security signals, and per-project TPM rate-limit / token-quota enforcement for model deployments. Source: https://learn.microsoft.com/en-us/azure/foundry/control-plane/overview

### ChatGPT Enterprise (OpenAI)
- **Codex Remote — General Availability** — phone→host agent control is now GA for all plans, secured by authenticated one-to-one QR pairing between each iOS/Android device and each connected Mac/Windows host. From a paired phone, users start threads in host projects, send follow-ups, answer agent questions, approve/deny commands, and review diffs/tests/terminal/screenshots. Source: https://developers.openai.com/codex/remote-connections
- **Codex DigitalOcean provisioning plugin (public preview)** — connects a DigitalOcean account via OAuth and lets Codex provision and configure a Droplet (from the Codex Universal image, with CLI/tooling/SSH pre-wired) as an on-demand remote workspace, no doctl/API tokens required. Source: https://www.digitalocean.com/blog/run-codex-in-the-cloud
- **Codex CLI 0.142.2** — MCP tools now use tool search by default where supported (new default MCP tool-discovery behavior), and remote stdio MCP servers accept absolute working directories in platform-native path formats; adds a PowerShell approval gate for unlowered-AST command regions. Source: https://developers.openai.com/codex/changelog

### Windsurf (Devin Desktop)
- **Devin Local autonomous mode (v3.4.22)** — Devin Local (the Rust-rewritten successor to Cascade, available on every tier including Free) gains an autonomous mode that runs the agent without step-by-step supervision and surfaces reviewable diffs before push, with subagent support for subtasks. New local unsupervised agent-execution surface. Source: https://docs.devin.ai/desktop/changelog
- **`/mcp` command + live MCP server status dashboard (v3.4.22)** — a new in-session `/mcp` slash command with a live status dashboard for connected MCP servers, giving users a control/inspection surface over the agent's MCP tool connections. Source: https://docs.devin.ai/work-with-devin/devin-mcp
